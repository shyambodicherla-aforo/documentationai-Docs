## Prerequisites

<Callout kind="info">
Before starting, ensure you have:
- A modern web browser (Chrome, Firefox, Safari, or Edge)
- An email address for account verification
- Optional: Existing documents from GitHub, Google Drive, or local files for import
</Callout>

## Create Your Aforo Account

Follow these steps to sign up and log in to Aforo.

<Steps>
  <Step title="Visit Aforo" icon="globe">
    Open your browser and navigate to `https://app.aforo.com`.
  </Step>
  <Step title="Sign Up" icon="user-plus">
    Click **Sign Up** and enter your email, name, and password. Alternatively, use Google or GitHub for faster signup.
  </Step>
  <Step title="Verify Email" icon="mail">
    Check your inbox for a verification email from Aforo and click the link to activate your account.
  </Step>
  <Step title="Log In" icon="log-in">
    Return to `https://app.aforo.com` and log in with your credentials.
  </Step>
</Steps>

<Callout kind="tip">
Save your login details securely. Enable two-factor authentication in your account settings for added security.
</Callout>

## Set Up Your First Workspace

Workspaces organize your documentation projects. Create one now.

<Steps>
  <Step title="Create Workspace" icon="folder-plus">
    From the dashboard, click **New Workspace**. Name it `My Project Docs` and add a description like "Documentation for my app".
  </Step>
  <Step title="Customize Settings" icon="settings">
    Set permissions (public, private, or team access) and choose a default template like "API Docs" or "User Guide".
  </Step>
  <Step title="Save and Enter" icon="check-circle">
    Click **Create**. You'll land in your new workspace dashboard.
  </Step>
</Steps>

## Import Existing Documents

Bring in your current docs seamlessly.

<Tabs>
  <Tab title="Manual Upload" icon="upload">
    Drag and drop Markdown, PDF, or DOCX files into the workspace. Aforo auto-converts formats and generates a table of contents.
  </Tab>
  <Tab title="GitHub Repo" icon="github">
    Connect your GitHub account via **Integrations > GitHub**. Select a repo and import MDX or Markdown files directly.
  </Tab>
  <Tab title="Google Drive" icon="file-text">
    Link Google Drive, pick folders, and sync docs. Changes propagate automatically.
  </Tab>
</Tabs>

For API-based imports, use this example:

<CodeGroup tabs="cURL,JavaScript">
````bash
curl -X POST https://api.aforo.com/v1/workspaces/{workspaceId}/import \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "source": "github",
    "repo": "user/my-docs",
    "branch": "main"
  }'
````

````javascript
const response = await fetch(`https://api.aforo.com/v1/workspaces/${workspaceId}/import`, {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${YOUR_API_TOKEN}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    source: 'github',
    repo: 'user/my-docs',
    branch: 'main'
  })
});
````
</CodeGroup>
