## Overview

Aforo streamlines your documentation workflow. You create, organize, and collaborate on project docs in a centralized space. Teams benefit from real-time editing, version history, and powerful search to keep information accessible and up-to-date.

Aforo supports Markdown, embeds, and custom components. Maintain consistency across your projects while scaling documentation efforts effortlessly.

## Quick Start

Get up and running in minutes.

<Steps>

<Step title="Create Account" icon="user-plus">

  Visit `https://aforo.example.com` and sign up with your email.

</Step>

<Step title="New Workspace" icon="plus">

  Create a workspace for your project.

  ```javascript
  // Example: Initialize via API
  const workspace = await aforo.workspaces.create({
    name: "My Project",
    description: "Documentation hub"
  });
  ```

</Step>

<Step title="Add First Doc" icon="file-text">

  Upload or create your first Markdown file.

  <CodeGroup tabs="CLI,API">

  ````bash
  aforo docs create --workspace my-project --title "Getting Started"
  ````

  ````javascript
  const doc = await aforo.docs.create({
    workspaceId: "ws_123",
    title: "Getting Started",
    content: "# Welcome\nStart here."
  });
  ````

  </CodeGroup>

</Step>

<Step title="Invite Team" icon="mail">

  Share your workspace link and add collaborators.

</Step>

</Steps>
