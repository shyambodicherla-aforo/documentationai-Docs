## Upgrading to the Latest Version

<Callout kind="info">
Before upgrading, back up your documentation spaces to avoid data loss.
</Callout>

Follow these steps to upgrade Aforo smoothly:

<Steps>
<Step title="Check Current Version" icon="package">
Run the version check command:

````bash
aforo --version
````
</Step>

<Step title="Backup Data" icon="database">
Export your spaces:

````bash
aforo export --all > backup-$(date +%Y%m%d).zip
````
</Step>

<Step title="Update Package" icon="download">
Use your package manager:

<Tabs>
<Tab title="npm" icon="package">
````bash
npm update aforo
````
</Tab>
<Tab title="Docker" icon="docker">
````bash
docker pull aforo:latest
````
</Tab>
</Tabs>
</Step>

<Step title="Verify Installation" icon="check-circle">
Restart services and test:

````bash
aforo start --test
````
</Step>
</Steps>
